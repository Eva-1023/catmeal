# 本次小米监控屏幕录制分析方法

输入为 iPad 原始复制文件 `data/videos/ScreenRecording_10-03-2026 22-12-10_1.mp4`。原文件保留，分析产生的裁剪图另存到 `outputs/real-analysis`。

## 时间轴与采样

这段文件是加速回放的屏幕录制。视频 PTS 是录屏经过时间，左上角水印才是摄像头实际时间，二者不能使用固定倍速换算。将编码图像逆时针旋转 90 度后，以录屏时间每 0.5 秒抽一帧；Apple Vision 在本地读取每帧水印。相同的监控时间只计一个观测时刻，回放暂停不能增加观察时长。

监控画面自身常每次跳过约 12–16 秒，偶有更大的步长；提高录屏抽帧率不能恢复原回放没有展示的场景。最后报告说明实际覆盖区间，不外推 24 小时次数。若发现回退、无法读取的水印或大于 30 秒的跳跃，保留异常并切断事件连续性，不能用平滑曲线掩盖。

## 区域和候选

正向显示尺寸为 2360×1640。候选裁剪区域为 `[630,730,1210,1170]`，涵盖猫粮食盆、前方圆碗、饮水装置及其附近地面。`region-definition.jpg` 展示三个独立位置。

YOLO11n-seg 在裁剪区域上生成候选。实际测试发现黄色猫低头时常被标为 dog，因此保留 cat 与 dog 两类；该标签只用于召回候选，不作为猫身份或行为依据。最小置信度 0.15、分割面积 4500 像素及与喂食区域交叠的条件去掉食盆误报。另用局部时间中位数背景和图像变化检测，独立查找未被候选覆盖的活动；这些额外区间也逐段检查。

所有候选的连续抽帧都生成检查拼图。Codex 结合低头位置、前后行为、毛色、身体轮廓和蓬松尾巴逐段复核，并将判断写入 `visual-review.json`。这属于算法辅助、Codex 图像复核的本次统计，不是未经验证的全自动行为分类准确率声明，也不是用户人工确认。

## 事件规则

- 主统计：头部反复朝向可见猫粮的方形食盆，至少两个不同的监控时刻，观察跨度至少 10 秒。
- 同一只猫的主食盆行为中断不超过 60 秒时合并；两只猫同在食盆前分别记录。长时间离开后返回重新计数。
- 圆碗内容物无法仅凭画面确认，因此单列接触次数。透明饮水装置单列；靠近、路过、坐着或单独看食盆不计入进食主统计。
- 夜视不根据灰度恢复毛色；只在长毛、尾巴和连续行为足以对应白天个体时归属，否则保留身份不确定。
- 事件起止是首次和末次被观察到的行为时刻，含可能的短暂抬头。该跨度不是准确吞咽或实际进食时长，也无法估算克数。

## 复现与证据

使用已有 `.venv` 和锁定依赖。以下提取命令会重新生成中间文件；保留现有分析目录后再运行，避免覆盖本次证据。Apple Vision 需要 macOS，编译器使用系统 Swift。

```sh
.venv/bin/python scripts/analyze_screenrecording.py
.venv/bin/python scripts/detect_feeder_samples.py
swiftc -O scripts/ocr_clock.swift -o outputs/real-analysis/ocr_clock
.venv/bin/python scripts/run_clock_ocr.py
.venv/bin/python scripts/build_camera_timeline.py
.venv/bin/python scripts/build_real_proposals.py
.venv/bin/python scripts/audit_feeder_motion.py
# 逐帧水印变化补查。
.venv/bin/python scripts/audit_all_clock_changes.py
.venv/bin/python scripts/run_clock_ocr.py outputs/real-analysis/clock-change-audit
.venv/bin/python scripts/compare_clock_audit.py
# 对 proposals、motion-review、novel-sheets 拼图完成复核，保存 visual-review.json。
.venv/bin/python scripts/finalize_real_analysis.py
.venv/bin/python scripts/plot_real_results.py
.venv/bin/python scripts/verify_final_analysis.py
.venv/bin/python -m pytest -q
```

最终输出位于 `outputs/final-2026-10-03`：`report.html` 为按猫/行为筛选的证据报告，`统计结果.txt` 为文字报告，`daily_counts.csv` 为汇总，`events.csv` 和 `events.json` 为逐次明细，`evidence` 保留每个事件的水印与局部画面，`provenance.json` 固定输入与复核文件哈希。日后更改合并规则或圆碗用途时，应从保留的行为标注重新计算，不能把帧数直接作为次数。

本次全片解码 268,113 帧，基础抽帧 8,941 张，时间水印变化补查 4,013 张，额外检查 105 个基础抽帧未包含的监控时刻；两轮合计 4,010 个不同监控时刻，最大相邻间隔为 25 秒。独立背景变化检查的额外候选为人经过、昼夜切换和暂停变暗，均经查看排除。主统计在 30/60/120 秒合并阈值下均为黄色 5 次、灰色 12 次。
